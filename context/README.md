# Project Context

This folder contains the product requirements and persistent project state for FlowGuard.

## Reading Order

1. [Context handoff](context_handoff.md): project purpose, current state, and workflow.
2. [Status update](status_update.md): completed work and immediate next steps.
3. [Product requirements](flowguard_prd.md): draft scope and acceptance criteria.
4. [Implementation plan](implementation_plan.md): deterministic implementation specifications prepared for approval.
5. [Phase index](phases/README.md): ordered task views of the master plan, with a separate document for each phase.
6. [Decision log](decision_log.md): decisions and changes over time.
7. [Original ideas](project_ideas.md): historical alternatives, not the current requirements.

## Maintenance

Update the decision log when choices change. Update the handoff when project scope, architecture, or continuation instructions change. Update the status file when work is completed or new blockers arise.

The PRD incorporates approved scope decisions and delegated exact specifications. The user authorized publishing these documents and the separate phase files. Review the master plan and phase files before building; documentation publication does not authorize implementation.

All project work belongs in [harshshah-24/FlowGuard](https://github.com/harshshah-24/FlowGuard).
